# 波前、几何焦面和严格实体约束的联合精修

本例说明如何在固定像面、实际玻璃和名义实体边界下，同时降低多波长波前、轴向色焦差和场曲。项目处方、厂商目录、逐面数据和原始光线保留在本机；公开内容只包含方法、合成数学演示和经过筛选的无量纲结果。它不能重建私有镜头，也不声称找到了全局最优。

## 目标与可行域

将每个目标除以各自冻结的限值，取联合指标：

`Phi(x) = max(WFE_i(x)/cap_i, LCA(x)/cap_LCA, FC(x)/cap_FC)`。

镜片实体、球面实数域、空气净距、全光束通光、接口、固定窗口/像面和一阶性能作为原有硬约束保留。`Phi <= 1` 只是像质目标通过的必要条件，还必须完成同一处方的独立实体与原生核验。求解器返回成功、加权罚函数接近零或少量采样通过，都不能代替这个判定。

不同构型中的蓝光/其他监测波长不自动变成新的像质优化目标；其原本的实体传播检查仍保留。占位波长不应重复计入目标权重。材料选择使用冻结目录中的真实色散，并将离散材料搜索与连续几何精修分别记录。

## 局部模型和真实候选

波前保留带符号的瞳面 OPD 向量及其雅可比。局部二阶锥约束直接限制仿射 OPD 向量的加权范数，避免仅对 RMS 标量求导丢失相消方向。活塞和实际方向余弦的倾斜拟合属于冻结的波前定义；不能额外移走像面或扣除 defocus。

对几何和一阶约束建立局部模型，在有界信赖域内求解，再对候选执行完整的非线性实光线和原始零门检查。用实际下降与预测下降之比调整信赖域。缩小信赖域的拒绝步复用同一基点的导数；接受新基点后重新建立模型。

实体检查需要覆盖声明的完整机械半径、有限球面及外侧平肩，并考虑非相邻表面之间的碰撞。扩大 CA 后重算通光与实体；不能靠缩小声明外径或丢弃边缘光线取得可行性。

若使用约束交换或证明冗余行，省略的只能是子问题中的已证明冗余行。最终候选仍检查全部原始行。数值工作缓冲不构成负的物理余量；接近零的序列化实体结果另做高精度复核。

## 有限孔径几何焦面

对像面全部有效光线，使用真实斜率 `tx=L/N, ty=M/N`，强度权重归一到1。加权中心化后：

```text
dz_2D = -(Cov(x,tx) + Cov(y,ty)) / (Var(tx) + Var(ty))
dz_S  = -Cov(x,tx) / Var(tx)
dz_T  = -Cov(y,ty) / Var(ty)
dz_TS = (dz_S + dz_T) / 2
```

`dz_2D` 最小化二维质心光斑的平方 RMS；`dz_TS` 为两个一维焦位的平均，一般不与前者相等。轴向色焦差按冻结定义使用各波长轴上 `dz_2D` 的峰谷差；场曲使用同波长各场 `dz_TS` 相对轴上的偏移。

本案例的物方等效定义是像方位移除以固定像面实际逐波长倍率平方；其他共轭或两端介质应重新推导纵向倍率。不要把系统标称倍率直接替代实际倍率，也不要把近轴 AXCL/FCUR 曲线当成全孔径几何 RMS 焦面。

`focus_moments.py` 是无处方、无材料库的合成演示，用直接移动几何光线并数值最小化光斑平方 RMS 交叉验证协方差公式，另检验平移不变性与失败光线拒绝。运行：

```powershell
python examples/joint-wavefront-focus-20261112/focus_moments.py
```

该演示只验证数学与错误处理，不是私有光学设计的验收测试。

## 工作采样与独立验收

优化工作采样、密采样复核和原生对照分别保留。正式焦面检查使用51个光谱节点、全孔径二维积分、65个场点和独立局部极值搜索。波前至少用两种冻结的瞳面求积方式复核；原生对照还检查采样相同的截点、方向、光程与 OPD。任何失败、渐晕或非有限光线都使整组无效，不能过滤后重算较好指标。

每个完整检查点将处方、材料目录版本、采样、接口与所有报告绑定到同一文件哈希。上一轮完整最优点与最新工作点分别保存。改变材料、参数坐标或采样后，原有导数缓存不能当成新基点的数据。

## 原生导出与 MF 的实际问题

- 单个协调者拥有原生软件实例，计算子进程只负责波长局部追迹与导数。
- 文本文件读取可能截短字段；通过 API 显式设置并读回完整视场、波长、主波长、NA、归一化和零渐晕。
- 多构型 MF 以显式 `CONF` 开头，防止软件自动插入首行导致全部绝对行号偏移。先用不相邻行引用检查 `SUMM/PROD/DIVI/PROB` 的实际语义。
- 已安装接口的 `LoadMeritFunction` 返回 void。逐行检查类型、Target 和 Weight，不能只相信行数或一个有限的总 MF 值。
- 配置波长槽和表面号使用显式映射，区分不同 API 的零基/一基索引；保存后重新载入，核对配置、STOP、玻璃折射率、几何和 MF。
- 真光线焦面可由 `REAX/REAY/REAA/REAB/REAC` 和算术行构造，使用上述矩公式；完整 LCA 可用所有波长对的上下界表示。大规模 MF 是工作目标表达，仍需独立验收。
- ZMX 的 CA/机械半口径不能完整表达有限球面加平肩的实体。完整实体侧表和几何证据随私有交付包保留。

这些 API 行为来自本机版本的实际读回；其他版本需要重新检查，不保证字段、容量和序列化行为相同。

## 匿名结果

最终无量纲轨迹和原生核验摘要由 `summarize_private_evidence.py` 严格筛选后生成。该脚本只有在全部原设计目标和最终同处方原生核验通过后才产生最终结果；不会复制私有路径、处方哈希、材料名称、波长表、逐面数据或厂商目录。公开轨迹是从已有可行检查点开始的连续精修片段，不包含前期结构筛选、材料分支和失败路线，不能用它估算完整设计耗时。它也不是硬件基准，不能证明该方法对其他镜头必然收敛。

`history.json` 保留每个完整检查点的三个归一化指标，`convergence.png` 由该文件生成。可用 `plot_history.py --report history.json --out convergence.png` 重绘（需 Matplotlib）。
