# 14 片绿光成像系统：设计过程、Zemax 与完整 MF 案例

设计冻结：2026-11-12；公开整理：2026-11-13。

本案例完成了原始绿光 8 波长的名义光学目标、增强的镜片实体分配、独立加密检查和 Zemax 原生复核。系统由 10 片物镜、4 片 tube 与固定平行窗口组成，全球面，物方 NA=0.5、物高半径 1.25 mm、名义倍率 −8.9×。制造公差、装调及最终制造放行尚未完成。

这与仓库既有的 UV355 5 mm、NA=0.60 案例是不同系统，规格和结果不混用。

## 1. 设计过程与路线选择

| 阶段 | 主要动作 | 得到的判断 |
|---|---|---|
| 外部参照与规格冻结 | 测量参考黑盒公开接口上的一阶和成像性能，确定波长/构型、NA、物高、固定像面及指标定义 | 拟合外部功能与像质；不提取黑盒内部处方 |
| 真实结构实现 | 用真实玻璃、有限厚度球面、胶合或空气间隔实现物镜与 tube；恢复一阶矩阵、接口与完整通光 | 一阶可行只代表进入像差校正的起点 |
| 材料及结构分支 | 对真实目录单片/双片替换排名，恢复厚透镜几何后实光线复排；并探索增加片数等分支 | 线性材料排名不是实际像质排名；最终保留14片，不证明最少片数 |
| 联合连续精修 | 对曲率与顶点位置建立解析导数，以有符号 OPD 范数、焦面与物理约束求解信赖域 SOCP | 提案经实体投影、有限次非线性校正及完整实光线重算后才能接受 |
| 工程增强 | 完整机械径向域检查发现 tube 薄片问题，明确厚度、净距和通光储备分配，再联合重优化 | 全径最薄厚度提高；不能只报告中心厚度 |
| 规格复核与收尾 | 恢复用户原定绿光范围，纠正额外的全谱像质及质心色差门；加入绿光 MTF 参考改善 | 原始硬条件保持，探索目标与监测项分开 |
| 独立与原生闭环 | 加密视场/波长/瞳面，搜索局部最坏点，验证实体和同处方原生光线；构建 MF 并保存重载 | 同一最终处方的名义目标通过，另列制造未完成项 |

早期探索的全 15 波长像质上限不是用户原要求。蓝光与 790 nm 只监测像质，但全 15 波长的物理通光始终必须通过。按原始范围收尾不是修改原始绿光上限；旧范围的评分不能接到新范围的收敛曲线上。

| 595 nm 物方平均 T/S 场曲 | 0.533363759 µm | 相对同波长轴上，65场及局部搜索；≤0.7 µm |

## 3. Tube 加厚与制造性

Tube 机械直径44 mm、通光直径42 mm；完整实体跨度56.361454 mm，低于61.8 mm工程分配。参考接口平面不被当成未声明的实体包络盒。

| 镜片 | CT mm | 完整机械域最薄 mm | 名义最薄分配 mm |
|---|---:|---:|---:|
| T1 | 7.773095 | 2.031000 | 2.030 |
| T2 | 2.671000 | 2.671000 | 2.670 |
| T3 | 3.091300 | 2.671000 | 2.670 |
| T4 | 2.065710 | 2.031000 | 2.030 |

分配包含暂定0.03 mm厚度预算；全部声明实体、机械径向域、空气域和通光储备另行核对，不由CA内厚度代替。22个固定像面、无补偿单项扰动（R±0.01%、CT及组间空气±0.02 mm）中，6个波前超限、0个基础实体几何失效。最敏感项包括首面半径和T2厚度。它是敏感性筛查，不能解释为统计良率。

镜筒装入路径、倒角、压圈/隔圈、真实基准和补偿器、同时误差、材料批次、胶合应力、热行为、镀膜及荧光资格尚需专门验证。

## 4. Zemax 与 MF 使用

压缩包中的文件保持原生已核验版本的字节，不在发布时重写曲率、玻璃、配置或操作数。

| 文件 | 用途 |
|---|---|
| `Zemax/GREEN8_FULL_TARGETS_13CFG.ZMX` | 主处方，嵌入203427行完整MF |
| `Zemax/GREEN8_MANUFACTURING_FOCUS_13CFG.MF` | 完整MF独立文件，包含工程实体及焦面图 |
| `Zemax/GREEN8_CORE_GEOMETRY.MF` | 23030行核心MF，便于日常检查，不含完整焦面图 |
| `Zemax/GREEN8_MTF_REFERENCE_ONLY.ZMX`、`.MF` | 独立绿光8波长多色MTF对比；不能代替主约束 |
| `CASE_MANIFEST.json` | 包内文件大小与SHA256、冻结处方身份 |
| `verify_and_prepare_catalogs.py` | 标准库工具：校验包内文件，按冻结SHA复制使用者提供的OHARA目录 |

在有许可的 OpticStudio 2022 R2.02 或兼容版本中使用。首次复现：

1. 完整解压ZIP。运行下方校验命令核对文件身份。
2. 准备SHA匹配的OHARA AGF目录。用辅助脚本复制为项目所需的 `Zemax/GLASSCAT/OH9AD9D2.AGF`；固定窗 `FIXWIN.AGF` 已随案例提供。压缩包不附整份厂商OHARA目录。
3. 在Zemax中以项目目录打开主ZMX，确认只加载 `OH9AD9D2` 与 `FIXWIN`，玻璃无缺失。材料加载失败或目录不匹配时先修复，不接受自动换玻璃后的结果作为本案例复现。
4. 主文件已经含完整MF，无需重复导入；需要单独导入时按表选择。文件较大，可先查看核心MF；核心MF不能替代完整验收。

```powershell
python verify_and_prepare_catalogs.py --case-dir . --verify-only
python verify_and_prepare_catalogs.py --case-dir . --ohara-path "D:/Glasscat/OHARA.AGF"
```

原始4个配置分别承载绿光7槽、蓝光、595 nm和790 nm；配置5–13补足570–620 nm的51个焦面分析波长，不改变物理结构。原790配置的窗后位移保持。主文件的历史 `NAME` 字段继承初始结构标题，当前身份与完成状态以本说明、哈希和验收数据为准。

MF工作焦面使用GQ4×12，正式验收使用GQ20×64；小MF数值不代替独立验收。变量均固定，后续释放变量或换玻璃后需要重新验证。完整原生MF已核对实体算式和真实光线焦面算式，主ZMX已保存重载并逐配置核对几何、折射率、配置数和操作数行数。

## 5. 如何复用

复用的是材料/结构外层搜索、有符号残差、解析导数、受约束步长、完整接受链和验证方式。本案例数值不作为其他系统默认规格。公开插件既有计算覆盖及已知限制仍有效；本次发布设计方法和可检查的Zemax/MF案例，未将私有完整研究求解器包装成新增CLI。
