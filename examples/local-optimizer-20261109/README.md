# 局部优化与解析导数：可公开复现的合成单片

本例验证算法，采用独立的合成镜头和演示验收指标。它不是 UV355 高 NA 物镜的替代方案，也不代表衍射极限、制造放行或全局最优。代码、完整合成处方和结果均可公开；不含项目私有处方。

## 复现

在仓库根目录、已安装 NumPy 和 SciPy 的 Python 环境运行：

```powershell
python examples/local-optimizer-20261109/run.py --repeats 3 --out results/local-optimizer-example
```

不需要 Zemax 或 CUDA。输出目录保存各轮处方、收敛记录和完整验收数据。仓库只保存本次紧凑记录 [benchmark.json](benchmark.json) 和解析导数路线的合成处方 [best-model.json](best-model.json)。

固定 z=64 mm 的孔径光阑，物方视场半径 0–1 mm，波长 0.54/0.55/0.56 µm。变量为前后曲率、前面 A4 和像面位置；两种导数路线从完全相同的零向量开始，使用相同变量边界、约束、采样、停止规则和加密验收。

完整运行包含局部求解、自动最坏点交换、严格加密光学复核及最终几何/光线包络报告。交替采用 FD/A、A/FD、FD/A 的运行顺序。该机器上解析路线约缩短 **14.0%** 时间、减少 **39.6%** 候选评价；这不是其他镜头或硬件的通用提速保证。环境和每次实测值见 JSON。

所有六次运行均通过本例规定的验收。最坏波前约降低 82%，最终光斑也有明确余量。像高允许范围内的变化是多约束折衷，不能把所有单项都宣称为同时改善。

## 验证了哪些机制

1. **解析导数。** 通过曲面隐函数、Snell 折射和 OPL 的前向切线传播，继续求移动参考球面 OPD、移动方向基底上的活塞/倾斜拟合、RMS 波前、RMS 光斑及主光线像高导数。完整归一化约束 Jacobian 与独立中心差分的最大绝对差为 `3.94e-6`，低于本例验证上限 `1e-5`。
2. **自动约束交换。** 初始仅使用轴上 GQ4。独立扫描 11 个视场半径 × GQ12/GQ20 两个完整积分规则，识别边缘失败，将边缘的两套完整规则加入工作集；第二轮扫描全部通过。没有给孤立瞳面点任意分配波前积分权重。
3. **达标后提高余量。** 每轮数值可行后再运行 6 步归一化最小余量优化，保持全部已可行约束。末轮解析路线的最小优化余量从接近零提高至 0.0756；完整数据见 `margin_stages`，该余量对应本例配置的归一化门槛。数值可行判据和最终严格验收分开记录。
4. **确定性扰动。** 所有光学门槛同时覆盖名义、前曲率 ±`2e-5 mm⁻¹`、像面 ±`0.005 mm` 共五个场景。最终共检查 330 个波前/光斑/像高组合。这是指定场景检查，未推断统计良率。
5. **几何和实际通光。** 每个候选执行配置的名义几何门槛及完整声明视场/光谱的实际光线包络检查。最终五个场景再用 GQ12 和 96 方位精确边缘光线检查，均通过。成品外径 12 mm；最终全径最薄厚度约 3.016 mm，大于本例分配的 1.5 mm 下限及 0.02 mm 预算之和。

发射光线瞄准固定光阑，因而不随本例四个变量改变。其他项目若改变光阑前的光学结构，应提供相应的发射/瞄准导数。当前解析模块对无效射线、孔径边界、全反射和奇异交点返回明确的不可微状态；没有实现移动遮挡边界引起的射线总体/权重导数。

开发探查中，更紧的 0.12/0.20 λ 单片目标在当前光谱和变量范围内未通过，未计入成功结果。本次正式两路线比较统一使用上述 0.25 λ 指标。UV355 项目继续采用其独立的原验收要求。
