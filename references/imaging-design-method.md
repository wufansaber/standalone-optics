# 通用成像光学设计方法

这套流程从成像任务出发，把规格、初始结构、实光线优化、验证和交付连起来。可用于有限共轭物镜、中继和投影，也可用于无限物距相机、望远成像和多构型系统。系统形式决定初始结构和计算后端，项目验收规格决定最终评价量。

## 1. 把应用需求写成可计算规格

先冻结一张规格表，给每项写明单位、参考面、工况、统计规则和允许的补偿。缺少决定结构选型的参数时，可以先做有标注的假设并保留分支。

| 规格 | 需要定义的内容 |
|---|---|
| 共轭与成像尺度 | 物距、工作距离、像面或探测器位置。有限共轭给出倍率及符号，无限物距给出焦距或角度到像高的映射。 |
| 视场与光束 | 物高、物方角度或像高，注明半径、全幅或对角口径。给出 NA 或 F 数所在侧、光阑、远心要求和允许渐晕。 |
| 光谱和构型 | 波长、权重、参考波长、变焦位置、对焦距离及环境工况。权重用于相应的综合评价，各工况的硬限独立检查。 |
| 像质与测量 | 从 RMS 波前、RMS 光斑、畸变、场曲、像散、色差、MTF 等选择验收项。注明像面固定还是允许调焦、波前参考、空间频率和最坏值的取法。 |
| 结构与制造 | 总长和接口参考面、通光尺寸、片数、允许面型和材料、中心及边缘厚度、镜片径向最薄厚度、最小实体空气隙、装调与公差。 |

**硬约束**决定是否可行，例如规定工况下的最小通光量、机械总长上限和像质限值。**优化目标**用于在可行结构之间排序，例如成本、片数、像质余量。**诊断量**用于定位问题，例如 T/S 焦面、扇形图、瞳面 OPD 和逐面光线高度。同一物理量可以随项目要求承担不同角色。

## 2. 用一阶模型建立多个可追迹起点

1. **先定光路骨架。** 按共轭、视场、光阑与出入瞳、工作距离和装配空间，枚举少量有差异的结构族。优先探索组功率分配、组间距和光阑位置。保留每个可行结构族的代表解，避免在同一基线附近重复开跑。
2. **用一阶条件消去变量。** 对适合中心化一阶模型的系统，采用统一参考面与约定，例如光线向量 `(y, nθ)`。有限共轭在约定物面和像面解 `B = 0`、`A = m`，同时约束总长、工作距离和瞳位置。无限物距有焦成像按有效焦距、后焦、入瞳和角度到像高的映射建种子。大视场与高 NA 在进入实光线阶段后检查实际映射和孔径。
3. **把组功率实现为厚透镜。** 加入材料、厚度、曲率、真实空气隙及光阑。复算完整组矩阵和一阶成像条件，检查弧矢定义域、边缘厚度和实光线通光。组矩阵使用明确的顶点或其他共同参考面，调整组位置后重新计入参考面之间的传播。
4. **保留结构多样性。** 以可行性为门槛，结合一阶偏差、各组光焦度负担、边缘光线包络、像差趋势及制造余量排序。针对变焦，尽早把多焦段的共享部件和机械行程纳入种子。针对明显离轴的系统，可用基准光线附近的局部光线映射建立起点，再由三维追迹检查。

| 规格中的主导条件 | 起始结构优先比较的自由度 |
|---|---|
| 有限共轭、高 NA 或远心 | 先定位负责收光的组和孔径光阑，比较前部与后部光焦度分配、工作距离、主光线角和边缘光束口径。 |
| 无限物距、要求后焦空间 | 在同一焦距下比较不同前后组功率及间距组合，检查后焦、入瞳和边缘视场的口径。 |
| 总长或片数受限 | 把总长和片数写入候选生成规则，比较强弱功率分配、不同光阑位置与可用的色散、非球面自由度。 |
| 多焦段共用镜组 | 同时建立多个焦段的一阶映射，比较固定组与移动组的职责，并检查对焦和变倍行程。 |

一阶关系适合把规格变成有物理意义的搜索空间。材料色散、瞳像差、实际渐晕和全场成像须随厚透镜实光线一起评价。[MIT 2.71 Optics 课程讲义](https://ocw.mit.edu/courses/2-71-optics-spring-2009/pages/lecture-slides/)

## 3. 重构时优先恢复光线映射

缩短总长、减少镜片或更换技术路线时，先用原方案找出各组承担的成像、孔径控制和像差校正作用。记录共同基准面上的主光线、近边缘光线及若干中间瞳区光线的位置和方向，并保留焦面、像高和实体间隙基线。新设计没有旧处方时，从一阶目标和实光线可行种子建立基线。

- **缩短总长。** 联动搜索组功率比例、组间距和光阑位置，用全系统一阶关系守住共轭、倍率或焦距。再检查工作距离、口径、实体间隙和实光线像质。
- **减少镜片。** 把删片、合片和重新分配光焦度列成独立结构分支。分别用剩余表面的功率和色散自由度补偿，恢复焦点、通光和代表性光线映射后，再评估高阶像差。
- **保留分支和回退点。** 可以按若干中间规格分段逼近，例如何时收紧总长、扩展视场或提高 NA。每次保存满足当前条件的处方和固定的验证设置。

## 4. 把评价函数做成有尺度的残差

对需要精修的指标，给出目标与固定的物理尺度。例如对等式目标用 `r = (value - target) / scale`，对上限的超限量用 `r = max(0, value - limit) / scale`。尺度可取容许偏差或经定义的设计尺度，统一一个优化阶段内的权重和采样。联合评价视场、波长和构型，兼顾整体误差和接近限值的工况。项目以最坏像质验收时，在优化中持续追踪最差工况，验收时按每项规格取最坏值。

| 当前状态 | 优先评价和调整 |
|---|---|
| 光线失败、通光异常或离焦严重 | 查失败面、光阑映射、主光线和边缘光线，先恢复可追迹性、焦点、实体几何及基本成像。 |
| 实光线可追迹，残余像差较大 | 按评价口径检查瞳面 OPD、光斑、扇形图、焦移及色差。由像差与组灵敏度选变量。波前使用有定义的参考面、有效瞳和对齐规则。高像差阶段以这些量指导优化。 |
| 入围方案接近像质目标 | 加密采样并恢复全部工况。需要 MTF 时，选适用的衍射计算口径，明确像方频率、瞳面权重、方向和焦面，检查曲线收敛。项目把 MTF 用作诊断时，保留曲线供判读。 |

结构族、片数和玻璃候选用离散搜索管理。固定结构内，可对有界连续变量做局部最小二乘或带约束优化。用灵敏度筛掉贡献低或高度相关的自由度，采用变量尺度和有限步长，逐步开放曲率、组间距、材料或非球面等变量。每次接受候选前，用实光线重算目标与硬约束。停止条件可写为达到规定余量、达到预算，或连续若干轮的可行改进低于项目设定阈值。[Ansys OpticStudio 系统优化资料](https://optics.ansys.com/hc/en-us/sections/42618686047123-System-Optimization)

## 5. 把计算量集中到有希望的候选

| 层级 | 采样和任务 | 晋级依据 |
|---|---|---|
| 可行性 | 一阶模型、代表光线、几何和材料约束 | 共轭、光束、空间和几何成立。 |
| 粗筛 | 代表视场和波长、较小瞳面采样、并行批量追迹 | 分结构族保留可行候选。粗筛边界附近加算，减少采样误差导致的误淘汰。 |
| 精修 | 更丰富的视场、波长和瞳面，连续优化 | 全量硬约束通过，关注最差视场和收敛趋势。 |
| 独立复核 | 更密的视场和瞳面，补查局部极值、渐晕边界及完整构型 | 最坏值及其工况明确，采样加密后结论稳定。 |

先减少无效候选和优化自由度，再并行计算。少量精算或分支不规则的任务可用多核 CPU。适合打包的大量候选、瞳面光线或有限差分列可考虑 GPU。只有前段处方、发射条件和追迹定义一致时才复用缓存。用相同候选和采样验证 CPU/GPU 的结果、淘汰边界与入围排序，分别记录批处理用时和完整迭代用时。最终验收使用经核对的计算精度及采样。

## 6. 选计算后端，按同一口径验收

| 系统 | 计算路径 |
|---|---|
| 受支持的同轴顺序折射系统 | 内置 NumPy 内核可分析有限或无限物距处方，输出波前、光斑、常用像差与 MTF。内置 `seed` 可生成有限共轭三组起点。用 `screen` 或 `groups` 粗筛相应的已有处方。 |
| 含偏心、倾斜、反射、自由曲面或复杂孔径 | 选择支持对应面型、坐标变换、反射和孔径的三维追迹后端。复用规格表、结构筛选和验收记录。 |
| 变焦、多构型、特殊材料或工况 | 选择能表达所有构型、耦合变量和物理模型的后端。联合优化，逐构型检查硬约束。 |
| 需要偏振、杂散光、特殊衍射或统计公差 | 按要求选择能描述相应物理和制造分布的专项分析。把结果与名义成像验收关联。 |

同处方交叉验证时，对齐材料与折射率、坐标、光阑与瞳采样、渐晕处理、波长、焦面、OPD 参考和像差定义。先比代表光线的截点和方向，再比汇总指标。若暂时缺少合适的实光线后端，交付候选结构、一阶结果、假设和待验证项。

验收输出至少包括处方版本及哈希、求解器和材料版本、像面和调焦规则、采样设置、每项限值与最坏值、对应视场和波长或构型。同步复核实体几何。项目要求公差时，以制造和装配误差、补偿器及允许行程复核，记录统计条件和良率目标。[内核验证范围与测试口径](validated-scope.md) · [Ansys 顺序公差分析](https://optics.ansys.com/hc/en-us/articles/42661666289043-How-to-perform-a-sequential-tolerance-analysis)

可复制以下表头，按项目添加或移除评价项。

| 项目 | 限值与单位 | 参考面、采样和补偿 | 计算或实测值与最坏工况 | 判定 |
|---|---|---|---|---|
| 最坏 RMS 波前或约定的像质指标 | 待填 | 规定瞳面、波长和焦面 | 待填 | 待填 |
| 场曲与像散 | 待填 | 规定 T/S 焦面定义、基准及物方或像方换算 | 待填 | 待填 |
| 总长、最薄厚度及最小空气隙 | 待填 | 规定测量参考面及检查的径向范围 | 待填 | 待填 |

## 在其他项目中使用

提供系统类型、共轭与成像尺度、视场、光谱、NA 或 F 数、探测器、工作距离、包络、制造约束和验收限值。有处方时附模型、材料和原生参考；从零设计时给出可选技术和结构边界。

> 使用 $standalone-optics 按通用成像光学设计流程开展这个项目。先整理验收规格与未决项，给出不同组功率和光阑布局的候选。说明每条候选的一阶条件、可行性、对应求解器和淘汰原因。对可追迹的入围结构分级优化，交付处方、最坏工况、像差曲线与机械检查记录。

在支持的有限共轭三组起点上，可复现以下最小工作流。

```powershell
python scripts/optimize_optics.py seed --demo --workers 4 --dense-top 8 --verify-serial --out seed-report.json --best-model-out best-seed.json
python scripts/standalone_optics.py --model best-seed.json --aberrations --plot-dir plots --out analysis.json
```

配置新项目或使用 CPU/CUDA 粗筛时，按对应命令替换规格与模型。`--dense-top` 在已有视场和波长上加密瞳面，用于候选复排。独立验收另行配置视场、波长、瞳面和焦面规则。[初始结构和并行粗筛](optimization.md) · [安装与使用](install-and-use.md)

## UV355 物镜怎样用这套方法

这次重构先重新分配组功率并联动组间距，再把中后组减片作为独立结构分支，按基准面上的光线映射恢复可追迹性和像质。入围方案由 16 片减到 13 片，总长约 850 mm。最终按该项目的波前、场曲、像散和机械条件复核，MTF 曲线用于判读。减片由项目脚本执行，内置 CLI 提供相应处方的分析与粗筛。其他项目按自身规格选结构、评价量和限值。
