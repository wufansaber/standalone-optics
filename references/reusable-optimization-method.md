# 成像光学优化算法总结

更新：2026-11-13；原研究快照保留2026-11-11口径。面向光学设计人员与优化程序开发者。

本方法把**结构与材料的离散搜索、真实光线驱动的连续优化、独立验收**组成闭环。目标是减少无效初始结构和昂贵重复计算，使实际最坏工况持续改善。

这套流程可以用于多类成像系统；计算后端必须能够正确表达所设计的几何与物理。当前独立内核的具体覆盖范围见[验证范围](validated-scope.md)。本文第12节保留早期未达标的研究快照。后续[14片绿光案例](../examples/green8-14element/README.md)已按原始绿光范围通过独立、原生和增强名义实体复核，并公开Zemax/MF；制造放行未完成。

## 1. 先分清三个层次

| 层次 | 内容 | 判断依据 |
|---|---|---|
| 结构与材料 | 片数、组功率、光阑、胶合或空气间隔、真实玻璃组合 | 多种厚透镜结构和实际光线结果 |
| 连续精修 | 曲率、厚度、组间距及项目允许的其他变量 | 局部模型预测、实光线重算、实际约束 |
| 独立验收 | 加密视场、波长、瞳面，检查完整实体和全部指标 | 与优化工作集分开的最终报告 |

始终成立的边界包括模型有效性、规定通光、实体间隙、接口及项目指定的基本成像约束。波前、场曲和色差等性能目标可以在搜索阶段联合降低超差；全部指标满足各自正式限值后，才有资格进入最终验收。

临时步长限制、内点缓冲量和初始化焦位窗口属于求解策略。它们要与正式验收条件分别记录，避免工作目标的微小数值超差触发无意义的反复修复，也避免使用数值停止容差作为物理余量。

## 2. 把验收定义变成可计算数据

每项规格至少固定：单位、物方或像方、波长与构型、视场坐标、瞳面、参考面、统计规则、是否允许调焦。

- 波前：固定像面或允许的补偿、OPD参考球、活塞与倾斜处理、RMS权重。
- 场曲与像散：T/S焦位的求法、基准焦面、平均焦面或两者分离量。
- 色差：轴向焦差或横向像高差、相对参考波长或全波段峰谷值。
- 材料：厂家、牌号、目录版本与哈希、有效波段、逐波长折射率。
- 机械：有限光学球面、通光口径、实体外径、平肩、玻璃与空气域、完整径向最薄厚度。

一个项目的数值限值不能直接移植到另一个项目。改变采样、参考面、材料表、参数排列或几何语义后，导数和局部模型缓存必须失效。

## 3. 高效建立初始结构

先按共轭与空间分配组功率、组间距和光阑，再把一阶解实现为真实材料、有限厚度的镜片。有限共轭可在统一参考面和光线向量约定下使用ABCD的成像条件；厚透镜实现后重新计算矩阵与实光线。

保留不同结构族的代表解，例如不同前后组功率比、光阑位置、胶合方式和镜片数。只在同一基线附近增加随机起点，通常增加计算量而不增加有用的结构多样性。

高NA设计中，近轴成像成立之后仍可能存在很大的球差和色差。瞳面径向四次项也会投影到低阶径向系数；低阶系数较大不等于可以只靠移动高斯焦点解决。应结合原始OPD、实际焦位和像差模式判断。

## 4. 材料必须参与结构搜索

材料是离散变量，不能长期用连续折射率代替真实牌号。可采用以下顺序：

1. 在全部工作波长计算真实的n(λ)，检查目录身份、状态和有效波段。
2. 用组功率、色散斜率、部分色散或谱矩阵条件数筛选组合，记录正负功率负担。
3. 实现有限厚度、真实曲率和间隔，恢复基本成像与通光。
4. 用全NA实光线复排轴向焦差、场曲和固定像面波前。
5. 只对有希望的组合做连续精修；恢复基本成像后重新评估材料组合的收益。

近轴或薄透镜评分只是筛选代理。本案例中，一组材料的校准矩阵预测焦差约0.443µm，实际全NA值却约8.109µm；另一组在初始实光线筛选中降低了焦差，恢复一阶条件后收益又消失。**选材排名必须经过厚透镜恢复后的真实像差复核。**

可计算n(λ)不等于可采购、适合荧光应用或满足整机透过率；这些状态分别记录。厂家原始目录与受保护的处方保持私有。

## 5. 保留有符号残差，优化其范数

对第i个工况，构造包含瞳面权重及相应波长尺度的有符号OPD向量bᵢ，使其范数等于所定义的RMS波前。局部参数步长为d：

$
\widehat W_i(d)=\|b_i+J_i d\|_2.
$

直接对RMS标量做线性近似会丢失向量抵消方向及范数曲率。保留有符号向量，使用仿射向量的范数作为局部模型，更适合低波前精修。QR压缩矩阵[Jᵢ bᵢ]可以保留整个仿射模型的欧氏范数，减少子问题数据量。

压缩前后应检查零步范数、若干非零方向以及预测值的一致性。OPD参考、发射条件和倾斜拟合随参数变化时，其变化也必须计入导数。数学上的范数锥不改变镜片面型；全球面要求仍逐面检查。

## 6. 联合波前、场曲与轴向色差

对最坏工况验收，采用各指标相对正式限值的最大值。以波前、场曲和轴向色差为例：

$
\Phi(q)=\max\left\{
\max_i\frac{W_i(q)}{L_{W,i}},
\frac{\operatorname{PV}_\lambda f_\lambda(q)}{L_C},
\max_h\frac{|c_h(q)|}{L_F}
\right\}.
$

其中fλ是有明确参考的轴向焦位，cₕ是相对同波长轴上的场曲。各上限和观测定义来自项目。搜索中Φ>1的点标记为工作初始化；Φ≤1也只表示所检查的性能集合通过，完整验收还包括独立加密、物理及其他项目要求。

局部子问题可以最小化上界t：

$
\|b_i+J_i d\|_2\le L_{W,i}t,
\qquad |c_h+C_hd|\le L_Ft.
$

轴向焦差无需展开所有波长对。引入自由变量u：

$
u\le f_\lambda+F_\lambda d\le u+L_Ct.
$

这与限制全部波长的峰谷差等价，n个波长只需2n行。按L_C归一化u，避免单位造成病态尺度。真实验收仍按实际峰谷差重算。

局部模型预测、实际下降量、信赖域比值、二阶校正资格、最佳点与导出排序，都必须使用同一个Φ。波前原始数值单独保留。原始OPD中不添加代表其他指标的虚构RMS行。

### 为什么要同时控制绝对焦位

相对色差变小，整组焦面仍可能共同偏离探测器。本案例一个初始化点的色差和场曲已经满足限值，固定像面波前却明显变差。因此，便宜初始化可增加真实焦位的软锚或临时窗口；最终仍以固定像面波前和全部正式指标判断。

真实几何最佳焦位也不等于波前最优焦位。临时窗口用于建立可用起点，不作为新的最终验收项，也不通过重对焦掩盖固定像面的波前。

## 7. 用实际光线便宜地计算焦位与导数

在一段均匀像方介质中，记录像面光线位置p=(x,y)及斜率s=(dₓ/d_z,dᵧ/d_z)，其中d为光线方向。用原瞳面权重移除各自质心：

$
\Delta z_{2D}=-\frac{\sum w\,\Delta p\cdot\Delta s}
{\sum w\,\|\Delta s\|^2}.
$

本例子午面取y-z平面，分别对y和x计算相应协方差/方差，可得到T、S最佳焦位。一般视场应先按其定义的子午和弧矢方向投影位置与斜率。对点、方向和倍率的导数应用商法，即可得到焦位及物方换算的解析雅可比，通常无需为此计算完整波前导数。

本研究案例物像方均为空气，按每个波长的实际倍率平方换算；不同介质和其他系统应采用对应的纵向倍率。轴向焦位以固定像面为共同基准，不能把全局坐标直接除以随波长变化的倍率平方。

用直接传播到预测焦面及其两侧检查RMS最小值，再与独立追迹及多步长方向差分比较。保留差分相减噪声和失败结果，不能为使测试通过而静默修改阈值。

评价失败应保留失败面和原因。不能删除失败光线、缩小实际有效瞳，或给失败候选填入零波前来降低分数。

## 8. 信赖域、DLS与二阶修正

以尺度化参数建立局部模型，求得步长后重新追迹：

$
\rho=\frac{\Phi(q)-\Phi(q+d)}
{\widehat\Phi(0)-\widehat\Phi(d)}.
$

预测可靠且步长确实受信赖域限制时，可以扩大半径；模型与实际偏离时缩小。SLSQP的成功标志、有限性、预测约束残差、真实物理可行性和实际下降是不同信息，要同时记录。

二阶修正SOC用于补偿主提案造成的小幅非线性约束偏离。每次修正后重算全部硬门，并以校正后的总步长重新计算预测和实际联合下降。修正次数、位移和追迹成本均有预算。

对已经可行的工作缓冲，可取min(偏好余量, 当前正余量的一半)，保持零步可行。负的真实物理余量必须修复或拒绝，不能通过停止容差获得额外空间。

## 9. 工程实体应独立于通光口径

分别保存光束包络、CA、有限光学球面、平肩及完整机械外径。检查完整声明径向域内的玻璃厚度、所有有序实体对的间距、独立边缘和完整组装跨度。

胶合改空气间隔时，镜片分组发生变化。重新生成实体模型不能顺带缩小原机械外径；扩大通光面也必须重算邻接空气域。仅核中心厚度或两个面共同的较小口径会漏掉边缘干涉。

浮点计算接近零时，可对有争议的约束使用精确十进制抵消或向外舍入区间复核。证实非负与预留制造余量分别报告。名义几何通过不代表公差良率或制造放行。

## 10. 把计算量用于有希望的候选

| 手段 | 适用位置 | 必须保留的检查 |
|---|---|---|
| 基点缓存与QR复用 | 提案被拒、仅缩小信赖域时 | 新基点、采样或模型变化即失效 |
| 解析J或已验证的自动微分 | 参数较多、差分列昂贵 | 同点值/J、方向差分、失败分支检查 |
| 信赖盒冗余行筛选 | 内层线性约束很多时 | 证明整个盒都满足；返回步重查原完整行 |
| 值/J分离缓存 | 内层重复请求约束值时 | 身份和行序固定；需要J时重新完整计算 |
| 相同launch合并 | 多条约束共享真实光线时 | 不删约束或路径；核对状态及每行g/J |
| 多核CPU | 波长、构型、导数列或多个起点 | 单worker线程数与进程亲和性，避免嵌套过量 |
| GPU批量追迹 | 大量独立候选和光线的粗筛 | 同候选CPU对照、失败边界、精度与排名 |

GPU加速粗筛不代表局部求解器或整个设计过程已加速。比较时记录初始化、预热、传输、子问题、实际追迹、修复和独立验收时间。最终更应比较达到完整验收的总时间与成功率。

Zemax API可以作为独立基线、候选搜索或验收后端。同处方先对齐材料、坐标、发射、采样、焦面与OPD定义，再比较原始光线和汇总值。本地独立内核与原生软件各自报告其已验证范围。

## 11. 结构探索与全局搜索的使用方式

局部下降停滞后，先判断原因：像差模式、材料色谱、活跃实体、变量相关性、模型预测、子问题未收敛，或真实可行域受限。再选择组功率重分配、光阑变化、真实空气间隔、材料替代、增减片或多个结构起点。

Hammer、CMA-ES、模拟退火和鞍点构造可作为外层探索策略，每种方法都要做有预算的同项目对照。一个小系统上的结果不保证在高NA多材料系统上复现。零厚度或零间隔的数学构造需要恢复成可加工厚透镜，才能成为设计候选。

按结构族和材料作用保存档案，记录输入身份、实际工作量和失败原因。重复没有独立改善的队列应复盘，改变假设后再测试。有限次数失败不证明无解；局部收敛不证明全局最优或最少片数。

## 12. 本地研究的有限实测证据

以下是2026-11-11前后的历史实验快照；它们对应不同范围和计算预算，不能合并成一个全局加速倍数，也不能代替后续绿光案例的最终结果。

|---|---|---|
| 同父本20步，signed OPD范数模型与标量RMS模型 | 独立最大归一波前约9.846与12.050；实际FE为38与23，总耗时约276.8与146.3秒 | 范数模型在该次提案预算下得到更低指标，实际成本更高，不是等FE或等耗时竞赛 |
| 同处方原生RMS基线 | 24项条件最大绝对差约3.08×10⁻¹⁰λ | 该组相同定义与采样的数值一致性 |
| 原生半径变量Hammer短试验 | 120秒后没有得到更好候选 | 该次设置未改善，需要重新评估变量与结构 |

本案例的0.7µm与波前上限属于该项目。它们不构成其他镜头的默认规格。后续优化结果仍需要完整密采样、原生及项目工程验收。

## 13. 可迁移的执行模板

下面是后端无关的伪代码，表示职责分配，并非当前CLI已有的调用接口。

```python
for topology, materials in diverse_candidates(spec):
    model = realize_thick_lenses(topology, materials)
    freeze_spec_catalog_model(model)
    if not restore_and_check_physical_model(model):
        save_rejection(model)
        continue

    q = restore_basic_imaging_with_real_rays(model)
    if q is None:
        save_rejection(model)
        continue
    for _ in range(iteration_budget):
        measured = evaluate_real_metrics(q)
        local = build_signed_opd_and_joint_focus_model(q, measured)
        step = solve_trust_region(local, physical_and_basic_constraints)
        trial = bounded_soc_if_needed(q + step)
        actual = evaluate_real_metrics(trial)
        if actual.hard_passed and joint_actual_descent(actual, measured):
            q = trial
            save_working_checkpoint(q, actual)
        else:
            reduce_trust_region()

    report = independent_dense_acceptance(model_at(q))
    archive(model_at(q), report)
    if report.all_requirements_passed:
        keep_final_candidate(model_at(q))
```

最终候选之间再比较片数、总长、余量、材料与装调成本。波前较小但其他指标失败的点，和焦差可行但波前失败的点，应作为不同工作分支保存。

## 15. 达标阶段固化的算法与策略

后续[策略详解](green8-constrained-design-strategy.md)和[案例证据](../examples/green8-14element/evidence.json)补充以下实际执行的方法：

- 真实材料候选同时考虑被测波长与主波长参考变化，再经厚透镜恢复和实光线复排。
- Clarabel直接求解QR压缩的最坏波前SOCP，SLSQP负责有限的实体投影与非线性约束修正。
- 工程延拓保留原始物理底线；最终仅在完整工程分配下验收。
- 多色MTF先组合复OTF，包含重叠域、节点、权重和实际工作F数的变化。
- 用户原始硬要求、额外探索目标和监测项分开；改变范围后不拼接评分。
- 同一处方完成独立加密、原生、MF算术、保存重载与哈希闭环；制造放行单列。

这些新增细节与第12节早期实验的评分和耗时分别记录，不构成全流程加速倍数或全局最优证明。
