# 显微高精度光学：加工公差、加工边界与结构检查

核查日期：2026-11-11。适用于显微成像的球面/平面透镜、旋转非球面和反射镜的设计评审。下列规则加入 Standalone Optics 的设计流程；数值参考用于初始分配，须结合灵敏度、供应商确认和检测能力冻结为项目限值。高 NA、小直径、深凹面、薄弯月及特殊材料单独确认，不套用普通镜片能力表。

这是设计约束与评审规则，不是制造实测记录。当前 NumPy 后端仍只支持已验证的同轴顺序折射模型；反射镜和三维光机检查交给兼容后端。本页没有增加镜面追迹能力。

## 1. 证据与限值的使用

每项约束记录：对象/面号、物理量、单位、检查域、上下限、来源类别、来源 ID/版本/原页、工艺与材料、检测方法、名义值、最坏损失、余量及完成状态。来源类别分为用户要求、工程分配、供应商确认、文献经验和计算结果。文献或能力表不能自动变成供应商对本件的承诺。

项目登记表见 [JSON 模板](microscope-constraint-register.example.json)。其中 `null` 表示尚未分配或未验证，不代表零；登记表是评审数据，**不能直接作为** `--manufacturing-policy` 参数。把下表中已支持的项目值转入既有 [manufacturing-policy 示例](manufacturing-policy.example.json)，其余由相应分析或证据完成。

缺值的项目可继续探索；验收结论记为 `incomplete`，不能据此宣称可制造。违反硬限值记为 `failed`。只有检查范围内的全部必要项有证据且通过才记为 `passed`；适用项不能靠改为“不适用”消除。

## 2. 透镜与镜组的结构边界

| 检查项 | 约束及设计动作 | 检查域/证据 |
|---|---|---|
| 机械 OD、CA、毛坯径 | 分别定义最终外径、各面有效通光区、毛坯加工域；光线包络加偏心/倾斜/热变化预算仍在 CA 内 | 全场、全谱、完整瞳面、所有声明工况；边缘精确采样并独立加密 |
| 倒角与承靠 | CA 外依次留出必要非工作区、倒角/崩边区和实际承靠区；记录可重叠区域的几何依据 | 截面和机械图，禁止把同一径向余量重复分配 |
| CT、ET、最薄厚度 | 同时检查中心厚、机械外缘厚和完整机械域的最小厚度；最薄点可能在内部 | 完整真实面形，内部极值，公差后最薄位置 |
| 空气与外缘净距 | 检查所有玻璃对的共同径向域，另查各实际承靠半径处隔圈/肩面；轴上间隔不能代替边缘空间 | 光学实体＋有限厚度光阑＋镜筒＋压圈/胶层 |
| 面形存在性 | 球面常用分支 `r < |R|`；圆锥根号域及有限斜率；非球面全径/内部极值 | 机械域与加工域分别检查；截平环带须显式建模 |
| 薄弯月/强曲率 | 薄片变形、两面定心、夹具接触、陡面刀具/测头可达性分别评审 | 不以两面曲率相近推定可加工或强度足够 |
| 胶合、浸液与近接 | 显式给实体、胶层厚度/楔角/固化收缩/材料波段；胶合界面不按空气隙处理 | 胶合装调、热失配和化学兼容；禁止用任意空气下限替代 |
| 装入与调整 | 规定装入方向、逐件通过孔径、工具空间、紧固、调整行程和锁紧后位移 | 三维装配与运动路径；最终位置不干涉不能证明能装入 |
| 显微镜接口 | 固定工作距离、盖玻片厚度/折射率、浸液介质/温度、物面位置、筒镜/共轭及允许补偿 | 这些是项目光学输入/公差，不能当通用加工常数 |

同轴面以 `t(r)=z_rear+sag_rear(r)-z_front-sag_front(r)` 求实体厚度，以相邻实体的面形差求净距。机械半径扩大或非球面系数变化后全部重算。安装接触位置和矢高共同决定隔圈长度，依据 [S3]；具体接触宽度由本项目载荷和工艺确定。

## 3. 公差初始分配：参考数字的适用范围

| 物理量 | 可用的参考范围/级别 | 来源及采用限制 |
|---|---|---|
| 球面半径相对公差 | 典型 ±0.5%，精密 ±0.1%，高精密 ±0.01% | [S1] PDF133/印刷120，教材描述，非本件加工承诺；极平曲面宜改用曲率或光焦度误差 |
| 磨抛面形 PV | λ/4 相对容易，λ/10 常规可达，λ/20 可能实现 | [S1] PDF155/印刷142；必须明确检测波长和实际 CA，不能据此分配每面系统波前 |
| 磨抛粗糙度 RMS | 约 1 nm 的教材参考，更低量级可能实现 | [S1] 同页；粗糙度的空间带宽与仪器须另定，不是低频面形 RMS |
| CT 制造公差 | 精密 ±0.050 mm；高精密 ±0.020 mm | [V1] 10–100 mm 优选玻璃、f/1 或更慢原型光学面；不是最小允许 CT |
| OD 制造公差 | 精密 +0/−0.025 mm；高精密 +0/−0.010 mm | [V1] 同范围；单边公差须原样进入承靠/定心预算 |
| ETD（边厚差） | 精密 0.010 mm；高精密 0.005 mm | [V1] 其楔角表的 ETD 定义；不是偏心或光束偏折角 |
| 表面粗糙度 RMS | 精密 1 nm；高精密 0.5 nm | [V1] 原表为 10 Å / 5 Å，范围同上；检测带宽待确认 |

参考表中的 λ 是明确指定的检测波长。例：面形 PV 为 λ/10、λ_test=632.8 nm，则表面高度 PV 为 63.28 nm [S1]；这不是“系统波前 λ/10”，也不能按工作波长自动改变该实物高度误差。供应商 `waves/fringes` 若是干涉仪输出，应核对单程/双程、反射因子和已去除项后转换。

高精度显微物镜不预设统一的“偏心 5 µm”“面形 λ/20”“空气隙 0.3 mm”。逐面/逐片由性能灵敏度与可达工艺分配。既有 CT/ET 经验和 0.30 mm 项目示例见 [加工边界](manufacturing-boundaries.md)，仍保留原适用范围。

## 4. 球面与平面的专项检查

分别给半径/曲率误差、面形不规则度、表面粗糙度、划伤麻点、CT/OD、两面楔角和光轴对机械基准的定心/倾斜。注明曲率拟合、去活塞/倾斜/光焦度的约定，不能让拟合去掉本应由系统承担的误差。

定心角、机械偏心、透射光束偏折和 ETD 是不同量；除非给出两面曲率、折射率、接触基准及模型，不相互替代。平面件单列平面度、平行度/楔角。近半球、深凹、小口径或近同心弯月应在优化前确认磨抛、定心和干涉检测可达性。

## 5. 非球面的专项检查

非球面继承所有实体与公差检查，另增加以下项目。依据 [S1] 的非球面制造讨论、[S2] §3.6 及 [V2] 的误差定义。

| 项目 | 必须固定的定义与限制 |
|---|---|
| 面形表达 | 轴/原点/符号、单位、基准曲率、K、全部多项式项及顺序；本技能 `even_coefficients` 从 A2 开始，很多图纸从 A4 开始，禁止错位导入 |
| 非球面偏离 | 对明确的基准球或 BFS，给拟合口径、权重、允许去除项、最大偏离和偏离斜率；禁止只限制系数大小 |
| 加工可达性 | 全径最大名义斜率、局部曲率、拐点/反曲区、最大矢高、凹面工具与测头可达性、边缘塌边风险；由实际工艺给上限 |
| 斜率误差 | 实际面形相对名义面形的斜率残差，给 RMS/PV/最大值、积分长度、滤波、采样间隔和方向；不同窗口不可直接比较 |
| 空间频率 | 低频面形、中频纹理和高频粗糙度各给检测带宽/PSD 或项目等价指标；仅全口径 PV/RMS 不足以约束中频纹理 |
| 定心与装配 | 非球面轴相对 OD/基准面的位置和角度、两面轴一致性；加工前设计可检测的基准和装夹接口 |
| 检测 | 指定干涉/CGH/拼接/轮廓仪方法、覆盖 CA、陡面有效区域、测量不确定度、拼接/标定误差；提供原始残差图和去除项 |

**名义斜率 `|dz/dr|` 与制造斜率误差 `|d(δz)/dr|` 不同。** 当前 `maximum_surface_slope` 只检查前者。系数公差往往相关，应优先按可制造的残差面形模式、轴误差和已定义空间频率误差传播到系统，避免把所有 A 项当作独立同分布随机数。

## 6. 反射镜的专项检查

平面、球面及非球面反射镜均须声明前/后表面反射、有效反射区、基底实体/背面/边厚、镀膜、入射角与偏振。离轴片给母面、离轴量、截取边界与机械基准；不套用同轴圆片的径向避碰结论。

| 项目 | 设计约束 |
|---|---|
| 光束与包络 | 追迹入射和反射的完整光路，检查遮拦、折返净距、镜座、挡光和全部工况足迹；斜入射足迹不是简单圆形 CA |
| 面形到波前 | 近法向、单次反射、小法向高度误差下 `δW≈2δh` [S4]；局部斜入射的一阶 OPD 为 `2δh cos(i)`，属于局部近似，最终用实际足迹与完整系统复核 |
| 角度误差 | 平面镜在入射平面内的小倾斜使反射方向约变两倍；像点位移由具体系统传播，不能直接当作装配倾角限值 |
| 镀膜后验收 | 镀前/镀后面形、应力变形、反射率、相位/偏振、波段及 AOI 范围分别限定；后表面反射还包含基底传播与鬼像 |
| 支承和基底 | 基底厚度/轻量化、夹紧与胶点、支承印痕、重力姿态和热梯度；用结构/热模型的位移面进入光学模型 [S4] |
| 检测与预算 | 明确测量姿态、支承、温度、检测波长、单/双程、有效口径及去除项；台面面形通过不能代替安装状态通过 |

镜面表面 RMS/PV、反射波前 RMS/PV和最终系统 RMS/PV分别存储。同一镜面多次经过、相关变形和共用支承不能按独立误差简单 RSS。不同镜面也只有在统计独立和评价定义一致时才可使用 RSS。

## 7. 公差预算与设计接受规则

1. 先锁定名义性能和项目硬边界，逐参数正负扰动找敏感项，再分配实际可加工、可检测的公差。高 NA 项目保持真实瞳面和参考约定，不用旁轴估计替代最终追迹。
2. 几何下限使用 `名义值 − 下限 − 最坏损失 ≥ 0`，上限使用 `上限 − 名义值 − 最坏增加 ≥ 0`。预算注明CT、面形、偏心、倾斜、热变化及测量不确定度哪些已计入，避免重复计费或漏项。非对称、相关误差用对应有界分析。
3. 面形和光学性能通过受支持的系统误差模型计算。记录公差后最坏 WFE、MTF/指定频率、像高/畸变、远心性、焦面、工作距离和通光；由任务选择实际验收项。
4. 补偿器限定可操作自由度、行程/分辨率/调整顺序、锁紧误差。不能对每个视场/波长分别重新对焦，除非实际设备允许这种工作方式。
5. Monte Carlo 必须给分布、截断、相关性、样本数、随机种子、补偿规则、失败样本和良率不确定度；几何失败/追迹失败计入失败。灵敏度、RSS、最坏情况和统计良率各自标明方法，不能互当验证。
6. 分开输出 `optical_nominal`、`solid_geometry`、`ray_clearance`、`assembly`、`manufacturing_tolerance`、`metrology`。冻结的方案比较指标与阶段接受指标分别保存。无供应商和完整误差模型时，制造验收保持未完成。

## 8. 与当前运行时的对应

| 约束 | 当前可执行入口 | 范围外的补充检查 |
|---|---|---|
| CT/全径最薄厚/空气与外缘间隔 | `minimum_center_thickness_mm`、`minimum_radial_thickness_mm`、`minimum_air_gap_mm`、`minimum_rim_gap_mm` | 三维异形实体与安装路径 |
| OD、CA、机械余量 | `maximum_diameter_mm`、各面 `clear_radius_mm`/`mechanical_radius_mm`、`minimum_clear_to_mechanical_radial_margin_mm` | 把直径除以 2 后写入半径字段；倒角和承靠建模 |
| 全球面、名义斜率 | `all_spherical`、`maximum_surface_slope` | 非球面偏离、曲率/斜率误差、PSD和检测覆盖 |
| 已计算的最坏几何损失 | `center_thickness_budget_mm`、`radial_thickness_budget_mm`、`air_gap_budget_mm`、`rim_gap_budget_mm` | 预算传播由项目提供，标量预算不是 Monte Carlo |
| 实际通光 | 采用所安装版本支持的全路径包络检查；记录采样域 | 反射、离轴、连续域最坏位置需兼容后端 |
| 制造/检测/装配验收 | 本登记表及外部分析证据 | 当前名义几何报告不能自动通过这些项目 |

运行时只接收其已支持字段，不把未实现条目塞入 JSON 或假称其已经执行。技能按本页做完整评审，保留未完成项；原生调用仍遵守所在项目的有界命令和许可要求。
