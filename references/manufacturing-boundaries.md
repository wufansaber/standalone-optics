资料核查日期为 2026-11-08。建立初始结构、选择材料、删片、缩短总长和放大视场时，先建立项目的加工边界，再用实光线像质筛选。每个数字须记录单位、检查域、工艺和来源。参数来自用户、供应商确认、工程分配或教材经验时，分别标明。

## 选择可执行的边界

| 层次 | 检查内容 | 设计动作 |
|---|---|---|
| 实体与模型 | 曲面定义域、有限斜率、玻璃厚度为正、实体避碰、通光范围、材料与结构声明完整 | 违反时淘汰。缺少机械外径或实体定义时记录未完成项。 |
| 项目与工艺 | 材料、面型、直径和厚度上下限、间隙、总长、支承带、供应商加工检测范围 | 显式配置后作为硬门槛，给出约束值和实际余量。 |
| 经验与成本 | 厚径比、定心难度、近半球或极浅曲面、优选玻璃与样板半径 | 先作预警与方案排序。需要强制限制时由项目选定工艺和限值。 |
| 制造验收 | 公差叠加、检测口径和方法、热变形、胶层、装配良率 | 名义几何通过后继续验证，保留补偿器及其行程。 |

本模块的通过结论针对受支持模型的名义几何及显式配置。镜筒、隔圈、压圈、装入路径和制造误差的结论须由对应模型给出。

## 统一口径和实体定义

每片镜片至少定义两光学面的面号、最终机械外径 OD、各面有效通光直径 CA、光线包络与余量、倒角/Chip Zone、实际支承带。毛坯尺寸单独登记。胶合片、浸液间隔、空气间隔、盖玻片及平板按其物理角色声明，折射率相同的两个相邻实体也要能区分。

球面常用分支要求机械检查半径 `r < |R|`，边界处斜率趋于无穷。一般圆锥面还须检查根号域 `1-(1+K)c²r²`。带非球面项时，检查完整面形和斜率，包含中间半径的极值。对同轴旋转面，以顶点坐标和矢高定义

- `t(r) = z_rear + sag_rear(r) - z_front - sag_front(r)`。
- `g(r) = z_next_front + sag_next_front(r) - z_previous_rear - sag_previous_rear(r)`。

同时记录 CT、机械外缘 ET、完整半径域最薄厚度，以及相邻镜片各自承靠半径上的轴向占位。全系统玻璃对都要按共同半径检查，避免较小中间镜片掩盖两个大镜片之间的交叠。装配结构检查再加入台阶、隔圈和压紧件。截平环带或法兰需要明确几何模型，完整曲面失败后不能靠缩小检查半径把它变成通过。

OD、CT、有效面口径、Sag 和 OAH 互相关联，承靠尺寸宜采用能直接检测的量，并保留倒角与夹持区域。长曲率半径与环带并存时，口径对矢高误差敏感，可考虑台阶或明确的小直径基准。[Optimax 机械属性说明](https://go.optimaxsi.com/hubfs/Technical%20papers/Whitepaper%20PDFs/MechanicalAttributesRevC2.pdf)

## 如何给厚度、间隙和曲率选初值

| 项目 | 可借鉴的经验及适用条件 | 采用方式 |
|---|---|---|
| 普通磨抛玻璃负片 CT | Laikin 原页以 `D/CT<10` 为经济加工经验，说明更薄可加工但成本增加。Kingslake/Johnson 给出 CT 约为 D 的 6–10%，并限定讨论尺寸。 | 作为结构初始化和薄片预警，结合材料、曲率、装夹和检测复核。 |
| 普通正片机械边厚 | 资料库总结小口径约 1 mm、20–50 mm 级优先约 2 mm 的经验。正片 CT、负片 ET 由真实面形反算。 | 最终门槛采用供应商或本项目明确分配。微小物镜片、模压件、晶体和大镜单列工艺。 |
| 毛坯边缘 | Edmund 给出磨抛/定心毛坯直径比成品大 1 mm 时，边厚约 0.7 mm 以上的经验。 | 这是指定毛坯域的检查，须另存毛坯直径与下限。 |
| 强曲率与浅曲面 | Edmund 将 `|R| ≤ 0.7D` 和非平面面形矢高约 ≤0.1 mm 列为加工难点。 | 作工艺提示，纯平面是有效面型。避免把经验警戒线当成球面存在域。 |
| 薄弯月与定心 | 近同心片的磨抛两面对准和定心更困难，夹具接触直径与凸凹符号影响 Karow/Z 因子。 | 先选定心工艺、接触面和检测基准，超出工艺能力时改变组功率分工。 |
| 镜间空气隙 | 须容纳实体避碰、承靠、倒角、隔圈及公差和热变化。 | 逐接口规定最小值，胶合或近接间隔显式声明。 |

Edmund 的相关经验面向常规制造和装配，并讨论定心及实际公差分布。它们适合用来识别需供应商确认的候选。[Edmund 可制造性设计指南](https://www.edmundoptics.com/knowledge-center/application-notes/optics/tips-for-designing-manufacturable-lenses-and-assemblies/)

## 公差余量进入设计

每个检查项记录 `nominal_value`、`limit`、`nominal_margin`、`worst_case_loss` 和来源。按项目的最坏情况分配检查 `nominal_margin - worst_case_loss ≥ 0`。有真实统计分布、相关性和补偿器时再做 Monte Carlo，并报告良率与样本数。尺寸公差、面形误差、偏心/倾斜、玻璃批次和装配叠加各按对应物理量建模。数值优化器的收敛残差单独记录。

例如名义空气净距比要求仅多 0.001 mm，而相应误差最坏会损失 0.010 mm 时，该接口的公差余量为负，设计应调整间距、支承或补偿分配。这里的数字是计算示例。

图纸应给出机械基准、面型、材料批次、检测口径、参考波长及 PV/RMS 口径。ISO 10110-1:2019 用于图纸总体表示，10110-5:2026 用于面形，10110-6:2025 用于定心和倾斜。面形新版采用 nm 为首选单位，使用条纹单位仍需注明基准波长。标准的表达规则和供应商能力分别核对。[ISO 总则](https://www.iso.org/standard/57574.html) · [ISO 面形](https://www.iso.org/standard/86355.html) · [ISO 定心与倾斜](https://www.iso.org/standard/82181.html)

## 在优化中执行

1. 先确定工艺、材料、允许面型、实体分组和机械口径，建立有来源的配置。用户要求全球面时，逐面检查 `K=0` 及全部非球面项为零。一般插件继续支持项目允许的面型。
2. 种子、每个候选、局部步长和回退都先做几何检查，再算像质。软评价函数可指引逼近边界，接受候选和交付处方仍按硬门槛。
3. 通光包络扩大后，重新确定机械域及厚度/避碰条件。粗筛使用的低密度几何检查在最终阶段加密，并查内部极值。严格倾斜/离轴和镜筒装配由适用的三维后端复核。
4. 保存通过值、最坏位置、剩余余量、未完成项和源文件哈希。光学通过、名义几何通过、装配通过和制造验收使用各自的记录。

内置可执行检查的字段、命令与当前覆盖范围见下方“配置与运行”。资料尚不完整时，候选可作为明确标记的探索结果。交付制造结论前补齐工艺、机械口径、实体和公差证据。

## 配置与运行

从[字段示例](manufacturing-policy.example.json)另存本项目配置并替换数值、面号与来源。示例是 12 mm 合成单片的工程分配。单位统一为 mm，斜率为 `|dz/dr|`。面号采用处方中从第一实际面开始的 1-based 编号。

| 字段 | 用途 |
|---|---|
| `schema_version`、`policy_id`、`sources`、`notes` | 版本和数值来源。 |
| `all_spherical` | 本项目启用纯球面/平面约束，检查 K 和所有非球面项。 |
| `surfaces` | 按面号给 `clear_radius_mm`、`mechanical_radius_mm`。机械半径包含实体检查域。 |
| `lenses` | 显式给出每片 `front_surface`、`rear_surface`。共享胶合面可同时属于两片。 |
| `defaults` | 最小 CT、全径厚度、空气净距、外缘净距、机械径向余量、最大直径及可选最大斜率。所有限值与对应预算可按 `lenses` 逐片覆盖；共享面及接口遵守下文的保守合并规则。 |
| `*_budget_mm` | 各项事先计算的最坏误差损失，和名义门槛一起检查。需要包含哪些误差由本项目预算说明。 |
| `radial_samples` | 径向检查密度。结果附采样与极值处理方法。 |

只做实体检查可运行

```powershell
python scripts/standalone_optics.py --model lens.json --manufacturing-policy project-policy.json --manufacturing-only --out geometry.json
```

先检查几何再计算像质可运行

```powershell
python scripts/standalone_optics.py --model lens.json --manufacturing-policy project-policy.json --aberrations --out analysis.json
```

ZMX 仍需提供 `--glass-dir`。保存的 DIAM/MEMA 用于记录几何口径，CLAP 等已支持孔径的光学语义沿用原定义。编辑曲率或扩大视场后，还须用全场全谱的实际光线包络重新核对口径。

初始结构和优化筛选在配置 JSON 的 `screening.manufacturing_policy` 中放同一份配置对象。CPU、CUDA 和入围候选的 CPU 密采样均执行此门槛。候选报告含 `manufacturing` 和失败原因。默认探查会拦截能确认的物理无效结构，并将机械数据缺失标为 `incomplete`。显式提供加工配置后，未通过或数据未完成的候选均不能进入排名。模型单独复现原生结果时，常规光学分析继续使用其原有比较口径。

脚本处理受支持的同轴旋转折射实体，检查完整机械半径上的 CT/最薄厚度、所有玻璃对共同域的间隔、独立外缘净距、面型与配置余量。倾斜镜片、异形侧壁、复杂胶层、法兰/截平台、夹持变形及装入路径需要对应几何后端。射线通光检查、光机装配检查和公差统计分别出具结果。

### 逐片限值与实际光线接受链

2026-11-09 后续运行时代码已修复同日审查发现的两项接受链缺口，回归用例见 `tests/test_manufacturing_acceptance.py`。原审查记录保留当时未修复模块的结果。

`lenses` 中的厚度、直径、最大面形斜率、CA 到机械边缘的最小径向余量、空气/外缘净距及其预算均生效。逐片值覆盖该片的 `defaults`；共享胶合面需同时满足两片有效限值，斜率取较小上限、径向余量取较大下限。空气和外缘要求作用于该片两侧实际存在的相邻空气接口；分别比较两片各自的“最小值 + 预算”，采用较严格的完整要求，不把不同镜片的下限和预算交叉相加。共享胶合面不按空气隙检查。报告保存逐片、逐面、逐接口的生效值及接口要求所属镜片。

CPU 与 CUDA 候选接受共用严格 CPU 全路径通光复核。该复核对处方中**全部已声明视场及波长**使用当前内部瞳面节点、轴心光线和 64 条准确单位圆边缘光线，即使粗筛只选了部分视场/波长也不省略其他已声明组。每个有配置边界的表面都将实际光线截点半径与 CA、机械半径分别比较；越界、失败光线和负传播段阻止候选排名。检查保留原生光学孔径与完整发射光束，不会缩小光束来获得通过。报告中的 `ray_envelope` 保存采样范围、最坏光线和各面剩余径向余量。

正常分析命令在提供加工配置时也执行上述复核；`--manufacturing-only` 仍只检查名义实体和标量预算，不运行光线追迹。Python 接口 `audit_manufacturing(model, policy)` 也保持名义几何语义，实际通光需进一步调用 `audit_ray_envelope(system, geometry_report, pupil)`。这些通过状态不代表镜筒装配或制造良率通过。

当前通光门槛为有限采样检查，半径比较使用 `1e-9 mm` 数值容差；它没有认证视场或瞳面连续域，也不覆盖未写入处方的工况。最终设计须继续独立加密采样、搜索最坏位置。CUDA 负责像质评分，配置加工约束后的共享 CPU 全路径复核有额外计算成本，尚未融合到 GPU 评分内核中。
